# **App Name**: AgroWise

## Core Features:

- Role-Based Authentication: Authenticate users based on roles (Farmer, Agent, Government, Bank) using local JSON data and manage sessions in localStorage, redirecting to respective dashboards.
- Dashboard Rendering: Dynamically render dashboard content based on the user's role, including weather overviews, crop recommendations, market prices, and other relevant sections. Utilizes reusable card components, stat blocks and charts using mock data.
- Crop Search and Filtering: Implement a search feature across crops, fertilizers, and prices with filtering by soil type, rainfall, and temperature, utilizing the mock datasets.
- Data Visualization: Display data using charts (bar, line) for crop production statistics, weather risk mapping, and mandi prices, rendered from the mock JSON datasets.
- Admin Advisory Tool: Admins are presented with insights and suggestions, generated by the app, as they craft advisories for farmers

## Style Guidelines:

- Primary color: Warm green (#4CAF50) to evoke agriculture and nature.
- Background color: Light green (#F1F8E9) for a clean, spacious feel.
- Accent color: Earthy brown (#795548) to complement the green palette and provide a sense of stability.
- Body and headline font: 'PT Sans' (sans-serif) for a modern and readable design.
- Lucide Icons for a consistent and clean interface.
- Use rounded cards (rounded-2xl) and soft shadows to create depth and a visually premium feel.
- Framer Motion for animations: fadeIn, slideUp, and smooth hover scale effects to enhance user experience.
